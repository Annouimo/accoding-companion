# Companion Next · 03c 开发预览

基于 03b 双平台 CI 成功的 #29。新增真实文件夹选择、按需展开目录树、C/C++ 文件切换、普通 C99/C++17 编译、同目录新建与重命名、孤立样例恢复与显式 JSON 导入。文件树定期扫描展开目录（1.5s，最多 128 个目录，每次只列直接子项），不建立索引，不跟随链接，不显示点目录。当前文件及样例的快照在扫描/焦点/运行时检查，最多缓存四个文件的最近批次；不是永久状态。外部改名不猜测关联。观察到路径消失时保守确认旧样例。文件替换发生于两次扫描间可能无法识别，不承诺永久文件身份。

新建 C **暂时普通模板**，04 才引入默认 Exam Kit；不是最终产品行为。创建位置为选中文件父目录或当前根目录。重命名采用同目录硬链接+删除实现不覆盖，失败回滚，文件系统不支持硬链接则明确失败；不做跨目录移动。外部导入 JSON 通过原生选择器，追加须确认；孤立数据恢复复制不删除原数据。C++17 自动使用 CXX/g++/c++。每次运行仍使用保存后的磁盘源码。非安全沙箱。

## 构建/验证

Go 1.26、Node 22、已有 GCC/Clang。next/desktop/frontend 执行 npm install --ignore-scripts --no-audit --no-fund && npm run build；next/ 执行 go mod tidy、go test ./internal/localrun、go vet ./internal/localrun、go build -tags production ./desktop。CI 双平台仅 artifact。锁文件由 CI 生成并附带。旧版不改、不发布。

手动验收：打开单文件自动父目录；打开学期目录并展开子目录；外部新建/删除/保存，检查树与结果失效；切换文件验证缓存；重命名带样例文件，检查无覆盖；外部改名后手动恢复，原样例保留；导入另一目录 JSON；C++ iostream 正常编译；中文路径、断网、Windows 文件属性及 macOS 窗口关闭。真机未验证。
