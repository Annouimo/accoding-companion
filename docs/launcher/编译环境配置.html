配置 C/C++ 编译环境

Companion 需要调用电脑上已有的编译器来运行样例和提交前检查。它不会安装编译器或修改系统环境变量。请选择适合自己的方法；无需把每一种方法都做一遍。

Windows

方法一：使用已有的 Dev-C++

已经安装 Dev-C++ 时，无需重复安装 GCC。打开「工具 → 编译器选项」，在目录设置中找到包含 gcc.exe 和 g++.exe 的 bin 文件夹，例如 Dev-C++ 安装目录下的 TDM-GCC-64\bin 或 MinGW64\bin。记下完整路径，按照下文的 PATH 配置步骤 操作。

方法二：WinGet 一键安装（推荐用于尚无编译器的 x64 Windows）

打开 PowerShell，执行：

winget install --id BrechtSanders.WinLibs.POSIX.UCRT -e

安装完成后关闭并重新打开 PowerShell 和 Companion。WinGet 通常自动配置 PATH。如果下载失败（安装包来自 GitHub Releases），可以改用下面的国内镜像方案。

方法三：使用 MSYS2（国内镜像）

  1. 直接下载 MSYS2 x64 安装程序（清华大学镜像）。也可以打开清华镜像下载列表或MSYS2 官网选择安装包。
  2. 运行下载的 exe，建议使用默认安装目录 C:\msys64。安装完成后，从开始菜单打开 MSYS2 UCRT64。
  3. 在 MSYS2 UCRT64 终端中执行下面的换源命令。它将默认镜像地址替换为清华镜像；详情见清华镜像站换源说明。 
    sed -i "s#https\?://mirror.msys2.org/#https://mirrors.tuna.tsinghua.edu.cn/msys2/#g" /etc/pacman.d/mirrorlist*
  4. 更新 MSYS2： 
    pacman -Syu
    若提示关闭终端，按提示关闭，再重新打开 MSYS2 UCRT64，重复执行更新命令，直至更新完成。
  5. 安装 GCC 和 G++： 
    pacman -S --needed mingw-w64-ucrt-x86_64-gcc
    遇到确认提示时输入 Y 并回车。
  6. 将 C:\msys64\ucrt64\bin 添加到 Windows 用户 PATH（如果更改过安装位置，请使用实际目录）。不要添加 MSYS2 的 usr\bin。

以上 GCC 安装方案针对 x64 Windows。其他架构请使用兼容的编译器，或使用已有的 Dev-C++ 工具链。

如何配置 Windows PATH 环境变量？

PATH 告诉 Windows 去哪些文件夹寻找命令行程序。Dev-C++ 和 MSYS2 都可以使用以下步骤。

  1. 在 Windows 开始菜单搜索「编辑账户的环境变量」并打开。
  2. 在上方的「用户变量」区域找到 Path，选中并点击「编辑」。如果不存在，点击「新建」，变量名填 Path，变量值填编译器的 bin 目录。
  3. 在编辑窗口中点击「新建」，填写包含 gcc.exe 和 g++.exe 的文件夹的完整路径，例如 C:\msys64\ucrt64\bin。
  4. 逐层点击「确定」，保存设置。
  5. 关闭并重新打开 PowerShell、Companion 以及启动器，让新设置生效。

不要删除或覆盖 Path 中已有的其他条目；添加的是文件夹，不是 gcc.exe 文件本身。如果有多个 GCC 版本，可以通过 where.exe gcc 检查实际调用的路径。

macOS

打开终端，安装 Apple 命令行开发工具，按弹窗提示完成安装：

xcode-select --install

Companion 默认使用 cc 和 c++（通常为 Apple Clang），不需要额外安装 GCC。

Linux

Ubuntu / Debian 用户可执行：

sudo apt update
sudo apt install build-essential

其他发行版请使用相应的包管理器安装 GCC 和 G++。

验证与排查

重新打开 PowerShell（Windows），执行：

gcc --version
g++ --version

macOS / Linux 用户执行：

cc --version
c++ --version

能够显示版本说明终端可以找到编译器。只学习 C 语言时，C 编译器可用即可。回到 Companion，重新运行样例以验证实际编译、链接和运行。

不想修改 PATH？

在 Companion「设置 → 设置 C / C++ 编译器」中分别填写编译器可执行文件的完整路径（例如 C:\msys64\ucrt64\bin\gcc.exe），输入 auto 恢复系统默认。

如果是源码语法错误、链接错误或样例答案错误，应查看对应的报错，而不是直接重新安装 GCC。
