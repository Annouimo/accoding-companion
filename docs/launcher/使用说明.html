安装和首次启动

打开启动器

完整解压启动包。Windows 双击 Accoding Launcher.exe，macOS 双击 Accoding Launcher.command。还没安装时，第一次打开启动器会自动显示这份指南。读完可以切回终端继续。

只需解压一次。以后从解压后的文件夹打开启动器；想再看这份指南，可以选「使用说明」。终端里的 › 表示当前选项，用方向键移动，按回车确认。

跟随进度完成安装

选择「安装」并按回车。保持联网，启动器会准备 Node.js，安装 Companion 和 C Exam Kit。启动器不安装或检查 C/C++ 编译器；即使没有编译器，也可以正常安装和启动。

下载期间让启动器保持打开。若因断网失败，恢复联网后返回首页，重新选「安装」。看到「安装已就绪」后即可启动。

启动 Companion

看到「安装已就绪」，按回车启动 Companion。首次打开时，首页通常只有「导入」和「设置」。接下来先找到要导入的比赛，不必提前进入设置配置账号或课程文件夹。

课程文件夹和比赛

在 Accoding 找到比赛 ID

打开课程，选择左侧「课程比赛」。在比赛标题同一行的第一列找到「比赛ID」。期末复习赛这行是 1359。

导入比赛并登录

回到 Companion，选择「导入 → 导入比赛 / 作业」。如果尚未登录，软件会自动打开 Accoding 登录界面。输入课程平台的账号和密码，用 Tab 切换字段，Space 勾选保持登录，再按 Enter。共用电脑上建议不勾选保持登录。

首次配置课程文件夹

首次导入时，如果还没有配置课程，输入比赛 ID 后，Companion 会提示「课程目录（可粘贴或拖入路径）」。课程文件夹是存放这门课所有比赛和题目的总目录。粘贴已有文件夹的完整路径，或输入希望新建的目录路径，按回车。首次配置该目录时，再选择 C 或 C++。

可以粘贴完整路径，也可以把已打开的课程文件夹拖进终端。已有课程代码时，选存放各场比赛的那一层。单场比赛目录和单题目录应放在这一层下面。

完成配置后，软件会继续导入比赛。导入完成后，打开比赛，再选择题目编号。以后导入同一门课的其他比赛时，会使用当前课程文件夹，不必重新配置。若要切换到另一门课程，再使用「设置 → 切换或新建课程」。

写代码、测试和提交

在编辑器中写代码

进入题目后选「打开代码目录」。打开 题目.md 和 main.c。C++ 课程使用 main.cpp。保留 C 题目模板里的脚手架头文件引用。把代码写在选中的题目文件夹里，保存后回到原来的终端窗口。

按 H 查函数

在使用 C Exam Kit 的课程中按 H，用方向键和回车浏览分类。例如选择「输入与输出 → 数字读写 → 读一个数」。使用 Tab 或 Shift+Tab 切换类型，签名与示例会同步改变。按 C 复制当前完整示例；/ 搜索函数名或中文用途。

上下方向键滚动，左右方向键查看长代码。R 查看相关操作（有相关条目时），U 查看通用使用约定（在目录页），G 返回首页，Esc 返回上一级，H 关闭手册并保留阅读位置。旧版资源的手册可能没有类型切换等功能。

运行样例

保存源文件，回到 Companion 选择「运行样例」。程序输出与预期不同的行会标出。先看第一条差异，再用上下方向键看其他行、左右方向键看长行。若提示编译失败，先根据报错修改源文件，再运行样例。若找不到编译器，Companion 会打开独立的编译环境配置指引。

提交通过样例的版本

选择「提交本次通过的版本」。确认要提交的题目和版本。修改代码后，保存并重新跑样例，再提交新版本。本地样例通过后，最终判题结果仍以 Accoding 为准。

更新工具与资源

查看更新版本

启动器首页会显示可以更新的组件和目标版本。选相应的「更新」操作即可安装。没有更新提示时，选「启动」继续使用当前版本。这里更新的是启动器管理的那份安装。

决定是否更新已有课程

更新资源包后，可以预览当前课程的更新。批量操作用本地模板判断是否写过代码，已改动的题目保留原来的资源版本。「无法确认」表示工具找不到可靠的原始模板作为对照，这些题也会保留原版本。可以先看预览再决定；以后也可以在 Companion 的「设置 → 更新课程资源」中处理。
