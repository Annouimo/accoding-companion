Accoding Companion 使用说明

从导入一场课程比赛开始，在自己的编辑器写代码，再用 Companion 测试和提交。

安装和启动选择课程文件夹 找比赛 ID写代码、测试和提交更新资源

安装和启动

  1. 完整解压下载的启动包。Windows 双击 Accoding Launcher.exe，macOS 双击 Accoding Launcher.command。
  2. 在启动器里选「安装」。启动器会检查 Node.js，并安装 Companion 和 C Exam Kit 资源包。首次安装需要联网。
  3. 看到安装完成后，选「启动」。以后打开启动器，可以直接选「启动」。
  4. 在 Companion 的「设置」里选「登录 Accoding」。在同一屏输入账号和密码，可选「保持登录」，再按 Enter。Tab 切换字段。

选哪一个课程文件夹

课程文件夹是这门课所有比赛和题目的上一级目录。 在「设置」里选「切换或新建课程」，再选一个已有文件夹或输入一个新路径。已有的 C 代码也可以留在这个目录里。第一次配置时，为此课程选 C99 或 C++17。

  • C-lang-course/ ← 选这一层
    • R-2026级C语言程序设计期末复习赛/ ← 导入比赛 1359 后生成
      • A-来岁昭昭的签到表/，里面有 题目.md 和 main.c
      • AA-gcd-lcm quiz/，里面也有自己的题目与源码
    • E8-2026级C语言程序设计第八次练习赛/ ← 同一个课程文件夹中的另一场比赛

你的目录可以叫别的名字。以后导入新比赛时，Companion 会继续把它放在这门课的目录下。

找到比赛 ID 并导入

  1. 在 Accoding 打开这门课，选左边的「课程比赛」。
  2. 找比赛标题，在同一行的第一列「比赛ID」取数字。期末复习赛的 ID 是 1359。
  3. 回到 Companion，选「导入」→「导入比赛 / 作业」，在「比赛 ID」输入 1359 并按回车。导入后进入比赛列表，再选要做的题。

写代码、测试和提交

  1. 在比赛中选择一道题，选「打开代码目录」。用自己的编辑器打开 题目.md 和 main.c，把答案写在 main.c。保留生成代码中引用 C99 资源的头文件。
  2. 想查函数时按 H。进入速查目录后，用方向键选择章节，按回车阅读，按 Esc 返回。
  3. 保存源码，回到 Companion 选「运行样例」。样例失败时，表格会显示样例输出和你的输出。上下键看后续行，左右键看长行。
  4. 样例通过后可选「提交本次通过的版本」。修改代码后重新跑样例，再提交新版本。

更新资源

启动器的「更新」安装新的 Companion 或资源包。资源包升级后，可以按提示预览当前课程的更新。确认时会显示课程路径、新题将使用的版本和旧题数量。批量更新会选择未改动的旧题，已经写过代码的题可以在 Companion 里单独选择和验证。
