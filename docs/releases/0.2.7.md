# Accoding Companion 0.2.7

本次更新重点是编译诊断与样例对比，不改变原有的题目管理、资源更新和提交工作流。

- 编译成功时也保留警告；常见警告附中文解释和本次源码上下文，警告不阻止评测或提交。
- 样例输出仅高亮不同字符，支持 N/P 跳转差异、方向键滚动、按屏翻页。
- 测试详情用 Tab / Shift+Tab 切换样例对比、编译诊断与运行日志，方括号切换样例或诊断；Enter 展开或收起已知诊断的原文。
- stderr 独立展示，不参与答案比较。诊断源码保留注释及行号映射，正式评测和上传仍使用同一份精简源码。
- 更新离线使用说明。无新增运行时依赖；C Exam Kit 资源包无需随本次更新升级。

## 安装与更新

现有用户需重新下载新版启动器以迁移至 Routilet npm 命名空间；已有课程文件和登录状态保留。首次使用请下载对应系统及架构的 ZIP，完整解压，Windows 双击 Accoding Launcher.exe，macOS 双击 Accoding Launcher.command。使用说明与编译环境配置指引随包提供。Linux 用户可以使用 npm 安装。

课程考试中能否使用相关工具，以课程规定为准。
