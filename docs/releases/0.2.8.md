# Accoding Companion 0.2.8 · Launcher 0.3.0

- 新增 C Observer 0.1.x：离线记录 C 程序执行状态，以全宽数据区为主，支持逐步回放、数组/矩阵/结构体及数据详情。采集区间变化不等于完整赋值日志。
- Launcher 0.3.0：统一安装和更新 Companion 及兼容依赖，暂存并验证后确认启用；支持失败保护、回退及稳定/预览渠道隔离。修复安装校验报错缺少具体命令和版本的问题。
- C Exam Kit 维持 0.6.10 兼容依赖。课程文件、已有资源快照及登录状态不因软件升级被删除。
- Observer 需要本机已安装相应调试工具链：macOS Clang/LLDB、Windows x64 GCC/GDB（支持 Python）、Linux x64 GDB/LLDB。缺少观察器或平台不受支持时仍可普通评测。

下载与系统及架构相符的启动器 ZIP，完整解压后双击 Accoding Launcher.exe（Windows）或 Accoding Launcher.command（macOS）。首次安装保持联网，默认选择稳定版渠道。包内含离线 HTML 使用说明及编译环境配置指引。考试中使用以课程规定为准。

本次正式发行后继续通过真实课程使用反馈调整界面、提示和回放体验。
